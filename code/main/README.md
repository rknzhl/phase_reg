# Ноутбуки

| Файл | Задача |
|---|---|
| `01_signal_analysis.ipynb` | Анализ сигнала: ACF, SSA/PCA, сфера и directional regression. |
| `02_ssa_tsne.ipynb` | SSA и t-SNE на всех окнах исходного опыта. |
| `03_phase_sections.ipynb` | Повторяющиеся события по пересечениям траектории с плоскостью. |
| `04_phase_mean.ipynb` | Фаза по средней траектории из 18 периодов по 460 точек. |
| `05_nadaraya_watson.ipynb` | Средняя PCA-траектория по заданным фазам. |
| `06_phase_nw.ipynb` | Вариант из GitHub: фиксированная средняя кривая и две функции потерь. |
| `07_paper_algorithm.ipynb` | Delay Embedding Phase Identifier: ACF, выбор размерности, три потери и обновление модели. |

Ноутбуки пронумерованы по порядку изучения. Разделы соответствуют шагам расчёта; перед кодом — короткие пояснения. Каждый ноутбук выполняется с чистого ядра из этой папки. Используются местные CSV из `data/`; файлы `.webarchive` в опытах не участвуют.

Из корня репозитория, Python 3.9:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Откройте нужный ноутбук в Jupyter или VS Code, выберите созданное окружение и выполните все ячейки. Рабочая папка — `code/main/`.

Графики и таблицы сохраняются внутри ноутбуков. Рисунок основного опыта — `code/main/output/phas_final.png`.

Основной ноутбук по статье — `07_paper_algorithm.ipynb`. В нём видны все формулы и функции; неопределённые в статье правила отмечены рядом с реализацией. [PDF-источник](../../docs/Kurdyukova2021Phase.pdf).

Исправления исходного кода:

- Добавлена реализация `NWregression` в `my_lib.py`; исходник импортируемой версии отсутствовал. Прямоугольное ядро исправлено на индикатор окрестности.
- Усреднение циклов больше не меняет исходный массив; `L1` считается отдельно для каждой фазы-кандидата.
- Исправлены индексы окон и остатки для статистических проверок. SSA использует экономное SVD; формула восстановления сохранена.
- `L3` не реализована; незавершённая альтернативная векторизация удалена. В `06_phase_nw.ipynb` средняя кривая не обновляется, начальные фазы заданы на всём отрезке, отдельного тестового участка нет.
